# Lyza Joyz Fontillas — Personal Portfolio

A responsive, frontend-only personal portfolio built with HTML5, CSS3, JavaScript, Bootstrap 5.3, and Bootstrap Icons.

## Run locally
1. Extract the ZIP file.
2. Open the `lyza-portfolio` folder in VS Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.

## Customize before publishing
- Replace `your.email@example.com` in `index.html` and `js/script.js` with your email address.
- Replace the GitHub and LinkedIn placeholder links with your actual profiles.
- Update each project link to its own GitHub repository.
- Add your own photo if you want a profile picture instead of the initials graphic.
- Review the About, skills, and project descriptions so they accurately represent your experience.

## Frontend-only note
The contact form uses a `mailto:` link to open the visitor's email application. It does not store messages or send data to a backend. Bootstrap and Google Fonts are loaded from CDNs, so an internet connection is needed for those assets.
